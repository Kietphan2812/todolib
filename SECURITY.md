# Security Policy

## Supported Versions

| Version | Supported                 |
| ------- | ------------------------- |
| 1.2.x   | Yes                       |
| 1.1.x   | Yes (critical fixes only) |
| < 1.1   | No                        |

## Reporting a Vulnerability

Please do NOT open a public issue for security vulnerabilities.

Report privately using one of these channels:

1. GitHub: Security tab > "Report a vulnerability"
2. Email: security@todolib.example

Please include: affected version, steps to reproduce, expected and
actual behavior, and the potential impact. A minimal reproducible
example helps us a lot.

## What to Expect

- Acknowledgement within 48 hours
- Assessment and initial response within 7 days
- Fix target: Critical 7 days, High 30 days, Medium 60 days, Low 90 days
- We will request the CVE ID ourselves, please do not do this on your own
- We will credit you in the advisory unless you prefer to stay anonymous

## Disclosure Policy

We follow coordinated (responsible) disclosure. Details are published
after a fix is released, no later than 90 days after the report.
