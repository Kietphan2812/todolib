# TodoLib

Thư viện Python quản lý danh sách công việc (dự án giả định dùng cho bài thực hành 8.7: quy trình xử lý security issue).

## Cài đặt

    pip install todolib

## Ví dụ

    from todolib import TodoList
    todos = TodoList()
    todos.add("Học bảo mật phần mềm")
